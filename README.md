#  Real-time Waste Detection & Classification: YOLO11s vs YOLOv8s

ระบบตรวจจับและคัดแยกประเภทวัตถุขยะแบบเรียลไทม์ผ่านกล้องเว็บแคม (Webcam Live Inference) โดยทำการพัฒนาและศึกษาเชิงเปรียบเทียบประสิทธิภาพ (Benchmarking) ระหว่างสถาปัตยกรรมปัญญาประดิษฐ์ยุคปัจจุบัน **YOLO11s** และรุ่นยอดนิยมในอดีตอย่าง **YOLOv8s** ร่วมกับการประมวลผลสัญญาณภาพด้วย **OpenCV** บนภาษา Python เพื่อศึกษาแบบจำลองที่ดีที่สุดสำหรับระบบจัดการขยะอัจฉริยะ (Smart Waste Management)

---

##  Features (คุณสมบัติเด่นของโปรเจกต์)
*   **Real-time Object Detection:** ตรวจจับ ตีกรอบ (Bounding Box) และระบุค่าความมั่นใจ (Confidence Score) ของวัตถุขยะผ่านกล้อง Webcam ด้วยความเร็วสูงแบบเรียลไทม์
*   **Multi-Class Classification:** รองรับการคัดแยกประเภทขยะหลัก 3 คลาสตามมาตรฐานสากล:
    1.  `General Waste` (ขยะทั่วไป)
    2.  `Hazardous Waste` (ขยะอันตราย)
    3.  `Recycle Waste` (ขยะรีไซเคิล)
*   **Multi-Version Data Augmentation Experiment:** ศึกษาและเปรียบเทียบผลลัพธ์ของโมเดลที่ผ่านการจัดเตรียมและเพิ่มขยายชุดข้อมูล (Data Augmentation) ทั้งหมด 4 เวอร์ชัน เพื่อวิเคราะห์สภาวะความทนทาน (Robustness) ของโมเดล

---

##  Dataset & Augmented Versions (รายละเอียดชุดข้อมูล)
ชุดข้อมูลอ้างอิงจากคลังข้อมูลวัตถุคัดแยกขยะ `WasteD` ผ่านแพลตฟอร์ม Roboflow Universe มีจำนวนรูปภาพรวม 1,557 ภาพ จัดแบ่งสัดส่วนสำหรับฝึกฝนเป็น **Train Set 1,509 ภาพ** และ **Validation Set 48 ภาพ** โดยการทดลองถูกแบ่งออกเป็น 4 เวอร์ชันหลักตามเทคนิคการทำ Augmentation:
*   **Version 1:** ชุดข้อมูลรูปภาพดิบตั้งต้นมาตรฐาน (Baseline)
*   **Version 2:** เทคนิคปรับแต่งสมดุลแสงสว่างและความมืด (Brightness Augmented)
*   **Version 3:** เทคนิคเพิ่มการหมุนภาพและการพลิกภาพสลับมุม (Flip & Rotate)
*   **Version 4:** เทคนิครวมทุกมิติ (พลิกภาพ, หมุนภาพ, บิดภาพ, ปรับแสง) เพื่อเพิ่มความหลากหลายสูงสุดป้องกันอาการ Overfitting

##  Summary of Experimental Results (ตารางสรุปผลเปรียบเทียบมหากาพย์)
ผลลัพธ์จากการทดลองฝึกฝนแบบจำลองจัดเต็มจำนวน **50 Epochs** ด้วยขนาดรูปภาพ **640x640 พิกเซล** บนสภาพแวดล้อมคลาวด์การ์ดจอ NVIDIA T4 GPU สรุปค่าประสิทธิภาพความแม่นยำและความเร็วได้ดังนี้:

| เวอร์ชันชุดข้อมูล | โมเดลปัญญาประดิษฐ์ | ความแม่นยำรวม (mAP50) | ความเร็วประมวลผลเฟรม (Inference) | พฤติกรรมเชิงวิชาการและการนำไปใช้งาน |
| :---: | :--- | :---: | :---: | :--- |
| **Version 1** | **YOLO11s** <br> **YOLOv8s** | 78.5% <br> **78.6%** | 🚀 **5.8 ms** <br> 30.3 ms | ให้ความแม่นยำสูงที่สุดทั้งสองรุ่นเนื่องจากภาพคมชัดสมบูรณ์ แต่ YOLO11s **เร็วกว่าถึง 5 เท่า** |
| **Version 2** | **YOLO11s** <br> **YOLOv8s** | 74.8% <br> **75.2%** | 5.8 ms <br> 5.5 ms | ตัวเลขความแม่นยำเกาะกลุ่มใกล้เคียงกัน โดยฝั่ง YOLO11s มีแต้มคลาส Recycle เด่นที่สุด |
| **Version 3** | **YOLO11s** <br> **YOLOv8s** | 76.0% <br> 76.0% | 5.6 ms <br> 5.5 ms | ขีดความสามารถความแม่นยำรวมและความเร็วการประมวลผลภาพ**เสมอกัน 100%** |
| **Version 4** | **YOLO11s** <br> **YOLOv8s** | 72.6% <br> **73.2%** | 🚀 **6.0 ms** <br> 10.8 ms | **มีความทนทานต่อกล้องจริงสูงสุด** โดยฝั่ง YOLO11s ประมวลผลได้ลื่นไหลเรียงเฟรมเสถียรกว่า |

>  **Conclusion for Live Demo:** แม้ว่า YOLOv8s จะทำคะแนน mAP50 เฉลี่ยบนชุดทดสอบเฉือนชนะไปในระดับทศนิยม แต่โครงงานชิ้นนี้เลือกใช้ **YOLO11s** เป็นแกนหลักในระบบเปิดใช้งานจริง (Live Demo) หน้าห้องเรียน เนื่องจากความสามารถในการประมวลผลเฟรมภาพคงที่และเร็วกว่าอย่างเห็นได้ชัด ทำให้ภาพหน้ากล้องมีความหน่วงต่ำสุดและลื่นไหลเป็นธรรมชาติ

##  How to Run (วิธีการติดตั้งและสั่งรันระบบกล้อง)

### 1. การติดตั้งสภาพแวดล้อมและ Libraries หลัก
เปิดช่อง Terminal ในโฟลเดอร์โปรเจกต์ของคุณแล้วรันคำสั่ง:
```bash
pip install ultralytics opencv-python
```

### 2. การเปิดใช้งานกล้องเว็บแคมสดตรวจจับขยะ
สามารถเลือกสั่งรันไฟล์แยกตามสถาปัตยกรรมโมเดลที่ต้องการนำเสนอได้อย่างง่ายดายผ่าน Terminal:

*   **สั่งรันโมเดลแกนหลัก YOLO11s:**
    ```bash
    python Test_camera.py
    ```
*   **สั่งรันโมเดลคู่เปรียบเทียบ YOLOv8s:**
    ```bash
    python test_camera_8.py
    ```

 **คู่มือการควบคุมระบบ:** เมื่อกล้องเปิดขึ้นมาแล้ว หากต้องการปิดหน้าต่างแบบปลอดภัยและคืนสิทธิ์หน้าจอให้แก่ระบบปฏิบัติการ Windows ให้คลิกเมาส์ที่หน้าต่างกล้อง 1 ครั้ง แล้ว**กดปุ่มตัว `q`** บนคีย์บอร์ด หรือกดปุ่มกากบาท `[X]` หน้าต่างจะปิดลงทันที
